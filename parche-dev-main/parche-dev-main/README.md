
# parche dev 2026

sitio oficial del encuentro parche dev 2026, construido solo con html semantico.

reto individual del modulo 1 - html y css, riwi.

## paginas

- inicio
- agenda
- ponentes
- inscripcion y confirmacion
- codigo de conducta

## como verlo en tu computador

1. clona el repositorio.
2. abre el proyecto en vs code.
3. abre index.html con live server.

## decisiones que tome

- use etiquetas semanticas como header, nav, main y footer para organizar mejor el contenido de cada pagina.
- use enlaces internos para navegar entre las paginas del sitio.
- use etiquetas label en el formulario para que cada campo tenga su nombre y sea mas facil de entender.

## lo que aprendi

- aprendi a organizar una pagina web usando html.
- aprendi a conectar varias paginas con enlaces.
- aprendi a crear formularios con diferentes tipos de campos.
